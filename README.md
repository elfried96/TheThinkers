# TheThinkers

Un projet de hackathon IA avec une architecture modulaire comprenant trois composants principaux :

## Structure du projet

### 🤖 IA/
Module d'intelligence artificielle contenant :
- Algorithmes de traitement d'images et OCR
- Modèles de machine learning
- Scripts de préprocessing et validation
- Intégration avec l'API Gemini

### 💻 Frontend/
Interface utilisateur (à développer)
- Interface web pour l'interaction utilisateur
- Visualisation des résultats
- Dashboard de gestion

### 🔧 Backend/
API et services backend (à développer)
- API REST pour la communication
- Gestion des données
- Services d'orchestration

## Installation et utilisation

### Module IA
```bash
cd IA
uv sync
uv run python main.py
```
